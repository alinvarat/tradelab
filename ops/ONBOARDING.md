# เริ่มงานกับ TradeLab (สำหรับผู้ร่วมงานใหม่และ AI ของเขา)

เป้าหมายเดียวของโปรเจกต์: บัญชีจำลอง 147 USD โต 3 เท่าต่อเดือนขึ้นไป ให้เร็วที่สุด งานที่ไม่ช่วยเป้านี้ไม่ต้องทำ

## 1. สิ่งที่เจ้าของต้องทำให้ก่อน (ครั้งเดียว)
1. เชิญเป็น collaborator ของ repo `alinvarat/tradelab` (GitHub → Settings → Collaborators) โดยใช้ชื่อผู้ใช้ GitHub ของผู้ร่วมงาน
2. ผู้ร่วมงานกดรับคำเชิญจากอีเมลหรือหน้า GitHub
3. ไม่ต้องให้ API key ใดๆ: CI, งานวิจัย และการ deploy ใช้ secret ที่ตั้งไว้ใน repo อยู่แล้ว

## 2. สิ่งที่ผู้ร่วมงานต้องมี
- บัญชี GitHub และ `gh` CLI ที่ล็อกอินแล้ว (`gh auth login`)
- AI สำหรับเขียนโค้ด (Claude Code, Codex หรือตัวอื่น) ที่อ่านไฟล์ `AGENTS.md` ได้
- ห้ามรันโปรเจกต์ในเครื่องตัวเอง: ทดสอบผ่าน CI และดูผลบน Kuber หรือ GitHub Actions เท่านั้น

## 3. ลำดับการอ่าน (ให้ AI อ่านก่อนเริ่มงาน)
1. `AGENTS.md`: กฎหลัก
2. `ops/SYSTEM_MAP.md`: อะไรรันที่ไหน และตรวจด้วยอะไร
3. `ops/RUNBOOK.md`: ขั้นตอนงานแต่ละประเภท, ด่านตรวจข้อมูล, สัญญาณอันตราย, นิยาม "เสร็จ"
4. `reports/STATUS.md`: สถานะและคิวงาน
5. issue ที่จะทำ

## 4. เลือกงานและทำงาน
1. ดู issue ที่เปิดอยู่: `gh issue list` เลือกตัวที่ยังไม่มีใครคอมเมนต์ว่ารับ
2. คอมเมนต์ "taking this" ใน issue นั้นก่อนเริ่ม เพื่อไม่ให้ทำซ้ำกับคนอื่น
3. สร้าง branch จาก `main` แล้วทำตาม RUNBOOK ของงานประเภทนั้น
4. เปิด PR ให้ CI ผ่าน แล้ว merge
5. อัปเดตแถวของงานใน `reports/STATUS.md` และคอมเมนต์ผลเป็นตัวเลขจริงใน issue

## 5. ข้อความสั้นสำหรับส่งให้ผู้ร่วมงาน (ใส่ Discord ได้)
```
ช่วยทำงานต่อใน repo alinvarat/tradelab หน่อย
ให้ AI ของนายอ่าน ops/ONBOARDING.md แล้วทำตามนั้น
https://github.com/alinvarat/tradelab/blob/main/ops/ONBOARDING.md
เลือก issue ที่ยังว่าง แล้วคอมเมนต์ว่า "taking this" ก่อนเริ่ม
```
