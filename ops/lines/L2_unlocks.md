# L2 short ก่อน token unlock

**สมมติฐาน:** เหรียญที่ใกล้วันปลดล็อกโทเค็นก้อนใหญ่ (มากกว่า 1% ของ supply ที่หมุนเวียน) มีราคาอ่อนตัวช่วงก่อนและหลังวันปลดล็อก
**หลักฐานเบื้องต้น:** 90% ของ 16,000 unlock events มีผลตอบแทน 30 วันติดลบ (Keyrock) ตามที่บันทึกใน `crypto_futures.md`

## ข้อมูล: ยังไม่มีแหล่งฟรีที่ตรวจแล้ว (ต้องแก้ก่อนเริ่มด่านคัดกรอง)
- `api.llama.fi/emissions` ต้องใช้แผนเสียเงิน
- `api.tokenomist.ai` ต้องใช้ API key

**งานแรก (จำกัดเวลา 2 ชม.):** หาแหล่งตาราง unlock ย้อนหลังที่ฟรี ตามลำดับนี้
1. หน้า unlock ของ CoinMarketCap หรือ CryptoRank: ดูว่ามี JSON ที่หน้าเว็บเรียกใช้หรือไม่ (ดูผ่าน network ของ Chrome)
2. GitHub dataset สาธารณะ เช่น repo ของ DefiLlama `emissions-adapters` ซึ่งเก็บตาราง vesting เป็นโค้ดเปิด
3. ประกาศ vesting ใน docs ของโปรเจกต์

ถ้าไม่พบภายใน 2 ชม. ให้ตั้งสถานะเส้นนี้เป็น `parked: no free data` แล้วเสนอเจ้าของว่าจะซื้อข้อมูลหรือไม่ (เจ้าของเคยตัดสินไม่ซื้อข้อมูลออปชัน จึงต้องถามใหม่เป็นรายกรณี)

## ด่านคัดกรอง (เมื่อมีข้อมูลแล้ว)
- **event:** unlock ที่มีขนาดมากกว่า 1% ของ circulating supply และเหรียญมี perp บน Binance หรือ OKX
- **กติกา:** short ตั้งแต่ T−14 วันถึง T+7 วัน ราคาจาก `data-api.binance.vision`
- **ต้นทุน:** หัก funding จริงของช่วงนั้น บวก taker 0.05% ต่อขา
- **control:** short เหรียญขนาดใกล้กันที่ไม่มี unlock ในช่วงเวลาเดียวกัน
- **แบ่งข้อมูล:** 2024 = train, 2025 = validation, 2026 = test
- **ผ่าน:** validation ได้ผลสุทธิมากกว่า 0 โดย p < 0.05
- **ตัด:** validation ได้ผลสุทธิ ≤ 0
