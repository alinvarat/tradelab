# L7 first red day: short วันแรกที่ปิดแดงหลังหุ้นเล็กวิ่งหลายวัน (Tim Sykes)

**สมมติฐาน:** หุ้นเล็กที่วิ่งขึ้นหลายวันติดกัน ("supernova") มักร่วงแรงเมื่อถึงวันแรกที่ปิดแดง การช้อต ณ ราคาเปิดของวันถัดไปแล้วถือสั้น ๆ จะได้ผลตอบแทนเชิงบวกหลังต้นทุน
**ที่มา:** Tim Sykes "first red day" (ดูตารางคอร์สใน `ops/knowledge/news_trading.md` บรรทัด Sykes) — เป็น **สมมติฐานจากคอร์ส ไม่ใช่ผลที่พิสูจน์แล้ว**

## ต่างจากงานที่ปิดแล้ว
- L3 (8-K นอกเวลา + gap ≥ 10%) และ L1e/L1f (delist) เป็นเหตุการณ์จากข่าว/ประกาศเส้นนี้ไม่ใช้ข่าวเลย ใช้ราคาและปริมาณล้วน ๆ เพื่อวัดว่าการเลือกจากรูปแบบราคาเพียงอย่างเดียวมีข้อมูลหรือไม่
- `momentum` 12-1 และ `pit_swing` ทำงานกับหุ้นใหญ่ใน universe ส่วนเส้นนี้อยู่ที่หุ้นเล็กที่ปั่นขึ้นหลายวัน ซึ่งเป็นคนละตลาด

## ข้อมูล
- **ราคาและปริมาณ:** Yahoo รายวัน (10 ปี) ผ่านตัวดึงเดิมของ `research/studies/run.py`
- **ตัวเทียบ:** IWM รายวัน (hut stocks เล็กเป็นตัวเทียบ; ยังไม่มี peer set แบบ point-in-time)
- ไม่เรียก LLM ไม่เสียค่าใช้จ่าย

## ด่านคัดกรอง
- **เหตุการณ์ (first red day):** ในวัน D หุ้นปิดแดง (`c < o`) หลังจาก 3 วันทำการก่อนหน้า (D-1, D-2, D-3) ปิดเขียวติดกันทุกวัน (`c > o`) และราคาวิ่งขึ้นจากปิดของ D-3 ถึงปิดของ D-1 ≥ 15%
- **หุ้นเล็ก ณ วัน D:** ปิดของ D-1 อยู่ที่ $1–20 และมูลค่าซื้อขายเฉลี่ยต่อวัน 20 วันอยู่ที่ $1–50M
- **ราคาเข้า:** ราคาเปิดของวัน D+1 (ไม่ใช่ราคาปิดของ D ซึ่งรู้สายเกินกว่าจะช้อต) ห้ามเข้าที่ราคาปิดของ D เอง — เป็นการตัดสินใจที่รู้ผลแล้ว
- **วัดผล:** ช้อตจากเปิด D+1 ถึงปิดที่ +1, +2, +5 วันทำการ IWM-adjusted หักต้นทุน 1% ไปกลับ
- **control:** IWM ในหน้าต่างเดียวกัน (ในโค้ดแล้ว) และรายงานผลที่ต้นทุน 2 เท่า
- **แบ่งข้อมูล:** 2019–2022 = train, 2023–2024 = validation, 2025–2026-10 = test
- **ผ่าน:** validation ได้ผลสุทธิมากกว่า 0 โดย block p (cluster = วัน UTC) < 0.05 และมีอย่างน้อย 3 เหตุการณ์ต่อสัปดาห์
- **ตัด:** ผลสุทธิของ validation ≤ 0 หรือ p > 0.2

## ข้อจำกัดที่ต้องรายงานตรง ๆ
- หุ้นเล็กอาจหุ้นยืมช้อตไม่ได้ในแอปจริง (เหมือน L3) ถ้าผ่าน ต้องระบุว่าต้องมีแหล่งยืมก่อนใช้จริง
- historic universe มาจากรายชื่อ ticker ปัจจุบัน → มี survivorship bias (เช่นเดียวกับทุก study ที่ใช้ `company_tickers_exchange.json`) ต้องระบุในผล
- "ปิดแดง" ของ D รู้ได้หลังปิดตลาด การเข้าเปิด D+1 จึงเป็นเวลาที่เร็วที่สุดที่ทำได้จริง ไม่ใช่การได้เปรียบจากอนาคต
