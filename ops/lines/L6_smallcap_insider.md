# L6 insider ซื้อในหุ้นเล็ก (Form 4)

**สมมติฐาน:** การซื้อในตลาดเปิดของผู้บริหารหุ้นเล็ก (transaction code P) ทำนายผลตอบแทนเชิงบวกได้ หลังหัก spread จริงของหุ้นเล็ก
**ต่างจากงานที่ปิดแล้ว:** study `form4` เดิมใช้หุ้นใน universe ซึ่งเป็นหุ้นใหญ่ ส่วนเส้นนี้ใช้เฉพาะหุ้นเล็ก และคิดต้นทุนแยกตามขนาดหุ้น

## ข้อมูล
- **Form 4:** SEC Insider Transactions data sets รายไตรมาส ใช้ `insider_purchases` ใน `core/studies.py`
- **ราคาและสภาพคล่อง:** Yahoo รายวัน คิดต้นทุนตามขนาดด้วย `liquidity_cost` และ `LIQ_TIERS` ใน `core/studies.py`

## ด่านคัดกรอง
- **event:** ซื้อมูลค่ามากกว่า $25k โดยหุ้นราคา $1–$20 และมูลค่าซื้อขายต่อวัน $0.5–20M
- **ราคาเข้า:** ราคาเปิดของวันหลังเวลายื่น (`acceptanceDateTime`)
- **วัดผล:** +5 และ +20 วันทำการ
- **control:** หุ้นเล็กขนาดใกล้กันที่สุ่มจากวันเดียวกัน
- **แบ่งข้อมูล:** 2019–2022 = train, 2023–2024 = validation, 2025–2026 = test
- **ผ่าน:** validation ได้ผลสุทธิมากกว่า 0 โดย p < 0.05
- **ตัด:** ผลสุทธิของ validation ≤ 0
