# L3 หุ้นเล็กที่มีข่าวนอกเวลาตลาด

**สมมติฐาน:** หุ้นเล็ก (ราคา $1–$20 และมูลค่าซื้อขายต่อวัน $1–50M) ที่มีข่าวหรือ 8-K ระหว่างตลาดปิด จะมีราคาไปต่อหรือกลับตัวอย่างคาดได้ ตามประเภทข่าวที่ LLM จัดกลุ่มให้ (ทุนเล็กเข้าได้ แต่กองทุนใหญ่เข้าไม่ได้)
**ความถี่ที่คาด:** หลายสิบเหตุการณ์ต่อวัน

## ข้อมูล
| ข้อมูล | ที่มา | หมายเหตุ |
|---|---|---|
| 8-K ย้อนหลัง | EDGAR daily `form.idx` (ใช้ `parse_form_idx` ใน `core/studies.py`) และ submissions API (`sec_filings` ใน `core/news_backtest.py`) | ต้องตั้งค่า `TRADELAB_SEC_UA` ผ่าน secret ซึ่งมีอยู่แล้ว |
| ค้นข้อความ 8-K | `https://efts.sec.gov/LATEST/search-index?q=<คำ>&forms=8-K&dateRange=custom&startdt=..&enddt=..` | ตรวจแล้วว่าใช้ได้ |
| ข่าว PR สด (สำหรับรันแบบเดินหน้าเท่านั้น) | `https://www.prnewswire.com/rss/news-releases-list.rss` | ตรวจแล้วว่าใช้ได้; GlobeNewswire และ BusinessWire RSS ใช้ไม่ได้ (Access Denied หรือถูกปิด) |
| ราคา | Yahoo chart รายวัน (มีย้อนหลังยาว) และ 1 นาทีที่มี pre-market (ย้อนหลังได้แค่ 30 วัน) | ใช้ `core/data.py` |
| รายชื่อหุ้นเล็ก | `https://www.sec.gov/files/company_tickers_exchange.json` แล้วกรองด้วยราคาและมูลค่าซื้อขายจาก Yahoo | ต้องคำนวณ ณ วันก่อนเหตุการณ์ เพื่อเลี่ยง look-ahead |

## ด่านคัดกรอง (ย้อนหลัง 2025-05-01 ถึง 2026-10-31)
1. **event:** 8-K ที่ `acceptanceDateTime` อยู่ระหว่าง 16:00 ET ของวันก่อน ถึง 09:00 ET ของวันเทรด
2. **จัดกลุ่มประเภทข่าว:** ใช้ item ของ 8-K (`item_tags`) ก่อนโดยไม่ใช้ LLM แล้วรัน LLM เฉพาะกลุ่มที่ผ่าน เพื่อคุมค่าใช้จ่าย
3. **ราคาเข้า:** ราคาเปิด (ใช้ข้อมูลรายวัน เพราะ 1 นาทีย้อนหลังไม่พอ) และคิดต้นทุนหุ้นเล็ก 1% ต่อรอบ
4. **วัดผล:** เปิดถึงปิด (`open→close`) และเปิดถึงปิดของวันถัดไป แยกทิศทางตามขนาด gap (มากกว่า +10%, น้อยกว่า −10%)
5. **control:** หุ้นเล็กกลุ่มเดียวกันที่ gap ขนาดใกล้กันในวันเดียวกันแต่ไม่มี 8-K
6. **แบ่งข้อมูล:** 2025-05 ถึง 2025-12 = train, 2026-01 ถึง 2026-06 = validation, 2026-07 ถึง 2026-10 = test

- **ผ่าน:** มีอย่างน้อย 1 กลุ่ม (ประเภทข่าว × ทิศ gap) ที่ validation ได้ผลสุทธิมากกว่า 0 และ p < 0.05 และกลุ่มนั้นมีอย่างน้อย 3 เหตุการณ์ต่อสัปดาห์
- **ตัด:** ไม่มีกลุ่มไหนผ่านเกณฑ์

**ความเสี่ยงที่ต้องรายงาน:** การ short หุ้นเล็กอาจยืมหุ้นไม่ได้ในแอปจริง ให้รายงานผลฝั่ง long และฝั่ง short แยกกัน

## ถ้าผ่าน
ใช้ระบบเทรดนอกเวลาของบอทที่มีอยู่ (`_extended` ใน `core/llm_trader.py`) เป็นตัวส่งคำสั่ง แต่ให้แยกบัญชีย่อยและแท็กโปรโตคอลใหม่
