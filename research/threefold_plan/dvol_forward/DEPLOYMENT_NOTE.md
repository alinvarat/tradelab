# Deployment note (2026-11-24) - the locked protocol.md is unchanged
protocol.md describes snapshots taken by a systemd timer on a personal machine. That machine is switched off by the owner's decision. The same snapshots (same code, same Monday 09:00:00-09:00:45 and 09:05:00-09:05:45 UTC slots, same window 2026-11-30..2027-02-22, 45-second slot, late or partial = week counts as cash) are now taken by the web app on Kuber (`core/dvol_collect.py`) into the persistent volume (`/app/data/dvol`). `/api/dvol` lists the files taken. Rules, sizing, costs and the evaluation are untouched. `evaluate.py` reads the folder named by TRADELAB_DVOL_DIR (default `raw/`); copy the files from the volume there to evaluate.
