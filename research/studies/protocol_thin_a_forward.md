# Protocol Thin A forward collectors (F1 new-listing capture, F2 cross-exchange gap, F3 announcement reaction)

Locked 2026-11-25, before the first poll. Rules in `research/studies/RESULTS.md` section "Thin A". Simulated money only; collection uses public market-data endpoints, no keys.

- **Poll:** hourly (`research.yml` job `thin_a`, input `study=thin_a_forward`, dispatched by a user systemd timer on the owner's machine because GitHub cron does not fire). State `state.json` and ledgers `ledger/f1_listings.jsonl`, `f2_gaps.jsonl`, `f3_announcements.jsonl` on branch `data/thin-a-forward`.
- **F1:** KuCoin, Gate.io, MEXC, Bitget USDT pairs with a live bid and ask. The first poll only seeds the seen set. A pair absent from the set later is a listing recorded at first sight; for 72 h each poll stores bid, ask, top sizes, 24 h volume and spread. A pair missing from two consecutive polls is recorded as `gone`, so pairs that die stay in the data (the survivorship that the historical screen cannot remove). Planned analysis: A1-A3 of the screen on the stored mid prices with the stored spread as the haircut.
- **F2:** every base quoted on a small venue and on Binance spot (data-api.binance.vision bookTicker). Executable gap = bid on the dear venue / ask on the cheap venue - 1, top of book, size >= 30 USD on both sides. Stored when >= 1.5%; mid-price ratios beyond 25% count as ticker collisions and are never stored as candidates. `persist` marks a base that was already a candidate one poll earlier. Deposit/withdraw flags come from the KuCoin, Gate and Bitget public currency endpoints (MEXC has none). Cost proxy: 0.1% fee per leg x 2 plus 0.5% rebalance/transfer = 0.7%. Verdict after >= 4 weeks and >= 60 persistent events with both withdrawals and deposits enabled: mean (gap - 0.7%) > 0 at double cost (1.4%). Gap measured here is a quote, not a fill; a pass would still need live depth and a transfer-time test.
- **F3:** KuCoin new-listings and Bitget coin-listings announcements (first poll is a backfill, not an event). For listed symbols that already trade on Binance, the Binance mid at the announcement poll and at +1 h, +4 h, +24 h, versus BTC. Gate and MEXC announcements are blocked and not covered.
- **Known limits:** hourly polls cannot see the first minutes after a listing; the first-seen time is accurate to one hour. Ticker endpoints give only the top of book.
