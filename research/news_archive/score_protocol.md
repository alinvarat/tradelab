# Does AI headline scoring beat the keyword lexicon? (locked 2026-11-23, before any score has a label)
Question: for headlines that mention a large cap, does the AI score (core/ai_news.py, model from env, default haiku) predict the stock's SPY-relative return better than the lexicon score?
Data: `data/ai_scores.jsonl` joined by `key` with `data/labels.jsonl` (abnormal return = stock return minus SPY return, first-sight price to +1h / +1d / +3d). Each headline-symbol pair counts once; headlines with more than one linked symbol use the first symbol only; AI rows with confidence < 0.3 are excluded for both scores (same sample).
Primary test: +1d horizon, Spearman rank correlation between score and abnormal return, for the AI score and for the lexicon score on the same rows; difference by bootstrap over headlines (2000 resamples, seed 20261123).
Nothing may be concluded before 200 usable pairs at +1d. Then: "AI useful" only if its correlation is > 0 with the 95% bootstrap interval excluding 0 AND exceeds the lexicon correlation with the interval of the difference excluding 0. Otherwise report "no demonstrated advantage". Even a positive result is a single in-sample window: it needs a later non-overlapping window before any score is used in a trading rule. +1h and +3d are reported as secondary, not used to decide.
Known limits: first-sight price comes from delayed Yahoo quotes; overlapping headlines about the same event are not independent; market-wide days inflate co-movement (SPY-relative return reduces, does not remove it); AI model text can change between versions, so the model name is stored per row.
