# แหล่งข้อมูลของการทดสอบความสนใจบน Wikipedia

- [Wikipedia Bitcoin](https://wikimedia.org/api/rest_v1/metrics/pageviews/per-article/en.wikipedia.org/all-access/user/Bitcoin/daily/2017120100/2025123100) และ [Wikipedia Ethereum](https://wikimedia.org/api/rest_v1/metrics/pageviews/per-article/en.wikipedia.org/all-access/user/Ethereum/daily/2017120100/2025123100) ใช้ตัวกรอง `user` ของ Wikimedia เพื่อวัดคนเปิดอ่านตามนิยามผู้ให้ข้อมูล ทุกวันในช่วงวัดผลมีค่าย้อนหลัง ชุดนี้รวมการเข้าผ่านเว็บและแอป ค่า daily ส่วนมากขึ้นภายในไม่กี่ชั่วโมงหลังจบช่วงและอาจช้ากว่า 24 ชั่วโมงเมื่อมีปัญหา ชุดย้อนหลังไม่มีเวลาที่เห็นจริงเป็นรายวัน [นิยาม](https://doc.wikimedia.org/generated-data-platform/aqs/analytics-api/concepts/page-views.html) · [ความล่าช้า](https://doc.wikimedia.org/generated-data-platform/aqs/analytics-api/documentation/troubleshooting.html)
- ใช้ราคาจาก `research.events.bars` ของ TradeLab โดยตัดช่วงที่ 2025-12-31 ตรวจฟิลด์เวลาของทั้ง BTC-USD และ ETH-USD แล้วว่าเป็น UTC และ timestamp อยู่ที่เที่ยงคืน UTC ทุกรายการ ราคาเปิดเป็นราคาอ้างอิงรายวัน การซื้อขายจำลองใส่ค่าเผื่อแทนราคาเสนอซื้อขายจริง [Yahoo BTC](https://query1.finance.yahoo.com/v8/finance/chart/BTC-USD?period1=1512086400&period2=1767225600&interval=1d) · [Yahoo ETH](https://query1.finance.yahoo.com/v8/finance/chart/ETH-USD?period1=1512086400&period2=1767225600&interval=1d)
- Google Trends web explore ตอบ 429 เมื่อขอหัวข้อ Bitcoin ช่วง 2018–2025 API ทางการระบุการเข้าถึงแบบ alpha และข้อมูลย้อนหลังแบบเลื่อน 5 ปี BigQuery ของ Google มีเฉพาะชุดคำค้นยอดนิยม/เพิ่มขึ้นเร็วตามพื้นที่และช่วงที่เปิด ไม่สามารถใช้ยืนยันว่ามีอนุกรม BTC ต่อวันต่อเนื่องครอบคลุมกติกาที่ล็อก [Google Trends API alpha](https://developers.google.com/search/apis/trends) · [ชุดข้อมูล Google Trends](https://support.google.com/trends/answer/12764470)
- Reddit public JSON ตอบ 403, Pushshift ตอบ 403 และ PullPush ตอบ 429 ตรวจข้อจำกัดจาก Reddit แล้วว่า Pushshift ทางการต้องได้รับอนุมัติและจำกัดงานดูแลชุมชน ชุด Wikipedia ใช้วัดการเปิดอ่านโดยตรงและเป็นตัวแทนความสนใจแบบหนึ่ง ส่วนอารมณ์จากข้อความ Reddit และปริมาณค้นหา Google ยังไม่มีผลทดสอบในงานนี้ [เงื่อนไข Pushshift](https://support.reddithelp.com/hc/en-us/articles/16470271632404-Pushshift-Access-Request) · [นโยบายการใช้ข้อมูล Reddit](https://support.reddithelp.com/hc/en-us/articles/42728983564564-Responsible-Builder-Policy)
- งานของ Kristoufek ใช้ช่วง 2011–2013 พบความสัมพันธ์และเหตุอาจวิ่งทั้งสองทาง งาน PLOS ONE ปี 2018 ที่ทดสอบ wavelet รายงานว่าความสัมพันธ์ของ BTC กับ Wikipedia แปรตามช่วงเวลาและรายงานรูปแบบ ETH ต่างจาก BTC เป็นหลักฐานความสัมพันธ์ย้อนหลัง ยังต้องทดสอบราคาที่เข้าได้และต้นทุนในกติกาปัจจุบัน [Kristoufek](https://www.nature.com/articles/srep03415) · [PLOS ONE](https://journals.plos.org/plosone/article?id=10.1371%2Fjournal.pone.0195200)
- ตรวจซ้ำด้วย `python3 -m research.world_signals.attention` จากข้อมูลที่เก็บใน `attention_inputs.json.gz` ได้ผลไฟล์ JSON เดิมทุกไบต์ ราคาขาด 0 วันและตัวเลขยอดอ่านขาด 0 วันในทุกช่วงวัดผล ตรวจสถิติจาก `attention_results.json`
