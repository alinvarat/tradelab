# VIX short-horizon fear crossover, locked before pulling the data

Hypothesis: increasing short-horizon fear relative to 30-day fear creates subsequent demand for near-dated volatility hedges. Cboe VIX9D crossing strictly above VIX from at or below it is the one signal. Watch actual UVXY exchange prices only, following issuer's change to 1.5× VIX futures objective in February 2018. Confirm crossover from adjacent index sessions. Enter the next US session open and sell the same session close. Use all available cash by fractional shares (explicit optimistic access assumption), no short or broker borrowing. Count no entries as cash. No overnight positions, fixed USD/THB scale $147 = 5,000 THB. Model 0.5% conversion on initial funding, 0.5% on hypothetical redemption and 0.25% transaction friction per side. Stress uses 0.5% per side and separately one additional session delay. Exchange opens and closes are representative prints, not fill guarantees. Any test choosing only UVXY cannot be generalized to delisted volatility funds.

Run periods 2019–2022 (comparison) and 2023–Oct 2026 (time holdout, new signal but historical retrospective). Track continuous cash, months above 3× and 6× including cash months, mean net event return, win rate, worst event and sequence drawdown after closes. Random-date control: same event count per month, sample without replacement from other sessions in same month, exclude actual event entry dates, 3,000 deterministic draws. If a month cannot supply enough control dates, mark the control unavailable. Do not optimize thresholds or replace this result with another holding period.

## Data alignment and diagnostics

Primary documentation: [Cboe daily index history](https://www.cboe.com/tradable-products/vix/vix-historical-data) and [ProShares UVXY](https://www.proshares.com/our-etfs/strategic/uvxy). Use Yahoo's original timestamp mapped to the New York exchange date. The VIX file contains 33 additional sessions with no regular UVXY bar, including U.S. holidays. Evaluate crossover only on adjacent regular UVXY sessions and verify both indices appear for each actual ETF session. Revenue uses open-to-close ratios, so split normalization cancels. The monthly target is relative to actual starting cash each month. Conversion is a one-time cash funding/redemption cost, so adding those charges to month-level multiples could only reduce results. Store control threshold counts in addition to comparison of event means. The p-value ranks matched random dates and is descriptive, without a cross-strategy multiplicity adjustment.

Replay offline with `python3 -m research.world_signals.vix_fear`. This test assumes liquidity at representative prices and fractional-share access. It does not establish broker availability, exact taxes/fees or intraday drawdown.
