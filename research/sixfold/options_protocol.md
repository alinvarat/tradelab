# กติกาก่อนดูผล • ออปชัน BTC นอกเงิน

- สมมติฐานคือซื้อสิทธิ์ BTC นอกเงินในทิศเดียวกับราคาที่เปลี่ยนใน 7 วันก่อนหน้า อาจได้ผลคืนหลายเท่าเมื่อ BTC วิ่งต่อจนข้ามราคาใช้สิทธิ์. ใช้ 2021–2023 เป็นข้อมูลอ้างอิง และ 2024–2025 เป็นช่วงล็อก. ทดสอบกติกาใหม่แบบย้อนหลังด้วยราคาที่ซื้อขายจริงใน venue. ตรวจ API ด้วยสัญญาตัวอย่าง 50,000-C ก่อนล็อกเพื่อดูว่าดึงย้อนหลังได้ ตัวอย่างนี้ไม่มีราคา strike ตรงกับกติกาหลักหรือทางเลือกเดือน ม.ค. 2024.
- ทุกวันที่ 1 เวลา 09:00 UTC หา index ล่าสุดที่รายงานใน trade BTC-PERPETUAL ในช่วงนาทีที่จบก่อนเวลาตัดสินใจ และทำเหมือนกันย้อนหลัง 7 วัน. ถ้าปัจจุบันสูงกว่า ชี้ call ถ้าต่ำกว่า ชี้ put ถ้าเท่ากันหรือไม่มีข้อมูลก่อนปิดนาทีให้ข้าม. เลือก expiry วันศุกร์สุดท้ายของเดือนเวลา 08:00 UTC และราคาใช้สิทธิ์ห่าง 20% จากดัชนีขณะตัดสินใจ ปัดออกด้านนอกเป็นช่องละ $1,000 (call ปัดขึ้น / put ปัดลง). ใช้ BTC inverse option ตรงกติกาเท่านั้น. ถ้าตัวนั้นไม่ได้ถูกสร้างก่อนตัดสินใจให้ข้ามเดือน ไม่ลอง strike อื่น. เดือนคำนวณจาก UTC.
- ตั้งงบจำลองสูงสุดทั้งบัญชี $147 (5,000 บาทตามสมมติฐานเดิมที่ตรึงอัตราแลก) ซื้อที่ first public buyer-initiated outright print ภายใน 120 นาทีหลังตัดสินใจ ทำเมื่อขนาด trade อย่างน้อยเท่าขั้นต่ำของสัญญา. ไม่นับ block, combo หรือ liquidation ที่มี flag. ซื้อเท่าที่งบรองรับตามขั้นต่ำและขนาดก้าวของสัญญา และไม่เกินขนาด actual print. ถ้า print แรกตามเกณฑ์มีราคาเล็กสุดเกินงบ ถือเงินสด ไม่ไล่ซื้อ print หลัง. ถ้าข้อมูลไม่ครบไม่มี fill. ค่าเปิดใช้ราคา print บวก 15% เป็น proxy ของ spread/slippage และ stress +35% บน print เดิม ตามข้อจำกัดประวัติ bid/ask และ queue ที่ดึงไม่ได้. ขนาด trade ไม่รับรองว่าคำสั่งของเราจะเติมได้.
- ค่าซื้อออปชันต่อหนึ่ง BTC ของสัญญาคือ min(0.0003 BTC, 12.5% × premium ที่เข้า) และค่าชำระออปชันที่มีมูลค่าใช้ min(0.00015 BTC, 12.5% × มูลค่า BTC ที่ชำระ). แปลง premium/ค่าธรรมเนียมจาก BTC เป็น USD ด้วย index ของ print และหักเพิ่ม 0.25% ค่าจัดหา BTC. เงินสดที่เหลือจำลองเป็น USD หลังหมดอายุแปลง BTC ที่ได้รับด้วยราคา delivery ทางการหัก 0.25%. ไม่มีขายก่อน expiry และนับ 6 เท่าเฉพาะยอดที่ชำระแล้ว. มีโอกาสเสียเต็มก้อนที่ใช้ซื้อ. คืนเงินส่วนที่ไม่ใช้ตามจำนวนเดิม.
- ทดลองกติกาหลัก 20% OTM และความทนที่ lock ได้แก่ ขยาย costs เป็น +35% ของ print, เปลี่ยน strike เป็น 10% OTM (ใช้ข้อมูลคนละสัญญา), และจำกัดเงินซื้อเหลือครึ่งบัญชี. คำนวณผลเดือนรีเซ็ตทุนทุกเดือนและทุนเดียวที่ทบต่อเนื่องโดยคำนึงถึงขั้นต่ำและขนาด trade ใหม่ทุกเดือน. สุ่มทิศ call/put ที่ 20% OTM เดือนเดียวกัน 1,000 ชุด ใช้ข้อมูลและกติกาซื้อของแต่ละ strike ตามจริง. ทั้งสัญญาที่ไม่มีอยู่และเดือนที่หา print ไม่ได้ถือเงินสดในการเทียบสุ่ม และรายงานสาเหตุแยกกัน.
- เกณฑ์คัดไปทดสอบต่อคือ 6× อย่างน้อยหนึ่งครั้งในแต่ละปีล็อก, ได้ 6× อย่างน้อยหนึ่งครั้งเมื่อเพิ่มต้นทุน, จำนวนเดือนเงินเหลือครึ่งหรือต่ำกว่าน้อยกว่าเดือน 6×, ค่ากลางเดือนล็อก >1× และชนะเดือน 6× ของวันสุ่มทิศที่ one-sided p < .05. ตรึงก่อนเก็บราคาของ strike ที่คำนวณจากกติกา.

## การดึงข้อมูลและตรวจผล

`python3 -m research.sixfold.options_fetch` ดึง trade archive ที่ `history.deribit.com` ผ่าน `get_last_trades_by_instrument_and_time` และดึง `get_instrument` และ `get_delivery_prices` จาก host หลัก `www.deribit.com`. บันทึกข้อมูล 60 เดือนลง `options_inputs.json.gz`. `get_order_book` บน host อดีตตอบ 400 ส่วน host ปัจจุบันส่งสถานะหมดอายุและ bid/ask ว่างสำหรับสัญญาที่ตรวจ ข้อมูลชุดนี้ให้ใช้ราคาอ้างอิงจากรายการซื้อขายที่เพิ่มต้นทุนตามสมมติฐาน. การไม่มี trade ตามหน้าต่างหรือไม่มีเครื่องมือที่ระบุให้ถือเงินสด. การแยกค่าธรรมเนียมและการชำระตามกติกาได้รับการตรวจจาก [Inverse Options](https://support.deribit.com/hc/en-us/articles/31424939096093-Inverse-Options) และ [Deribit Fees](https://support.deribit.com/hc/en-us/articles/25944746248989-Fees).

`python3 -m research.sixfold.options` อ่านข้อมูลที่เก็บไว้และเขียน `options_results.json`. รันซ้ำแบบไม่ดึงข้อมูลได้ผลตรงกัน. ตรวจด้วย API อิสระอีกครั้งสำหรับ trade ID 323206580 ที่เกิด 2024-11-01 09:19:43.396 UTC ในสัญญา `BTC-29NOV24-84000-C` และ settlement index วันที่ 2024-11-29. ราคา trade อ้างอิง 0.0135 BTC ต่อสัญญาและมูลค่าที่ settlement $95,843.77. ราคา trade และราคา settlement ยืนยันได้ ส่วนราคาซื้อที่บวก spread จำลองและการเติม 0.1 สัญญาเป็นสมมติฐาน.
