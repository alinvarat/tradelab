# Prior US volatility direction for weekly BTC options
Freeze before computing joint results. On each existing Monday 09:00 UTC use the latest Cboe VIX US close no later than the preceding Friday and use the analogous close one week earlier. Each anchor allows at most two calendar days of staleness. If VIX rose, buy BTC put; if VIX fell, buy call; ties or stale data go to cash. Use the same 8.5% OTM rule and archived expiry, half-wallet budget, purchase and exit tape, friction and 3×/6× cash exits. Report single continuous accounts over 2025, Jan–Oct 2026, and both, and compare 500 independent uniform random directions on the same eligible weeks. The inputs were individually used in previous studies; this joint replay is retrospective. No threshold search.
